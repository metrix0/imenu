# /auth
### What it does
Holds all routes related to menu Supabase Auth.

# /menu
### What it does
Holds all routes related to menu data:
- updating, adding, removing, listing menu items
- etc

# /orders
### What it does
Holds all routes related to costumer orders:
- create orders
- fetch and update order status
- etc

# /webhooks
### What it does
Holds all **external services callbacks (webhook)**:
- MercadoPago updating us when payment is done.

> A webhook is like an automated POST that another service calls when something happens
